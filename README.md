# 코드로그 (CodeLog)

코딩 공부 기록 앱입니다. 타이머, 10개 언어 학습(입문·중급·고급), 전문가 로드맵(서버·AI 외주까지), 메모장을 한곳에서 씁니다.

**사용하기**: GitHub Pages 주소로 접속하면 바로 실행됩니다(설치·서버 불필요). 이 저장소의 `index.html`을 내려받아 `content` 폴더와 함께 열어도 됩니다.

## 진행 기록 저장
- 진행 기록은 각자의 브라우저(localStorage)에만 저장되고, 이 저장소나 서버로 전송되지 않습니다.
- 설정 탭 → **파일 저장**으로 `codelog-backup-날짜.json` 파일을 내려받아 보관하고, **파일 열기 → 가져오기**로 다른 기기·브라우저에 옮길 수 있습니다.
- 일주일에 한 번 백업 알림이 뜹니다.
- 브라우저 데이터를 지우면 기록도 사라지니 가끔 파일로 저장해 두세요.

## 구성
- `index.html` : 앱 본체 (HTML·CSS·JS 한 파일)
- `content/` : 언어 교재(`*.js`)와 전문가 로드맵 모듈(`pro/*.js`)

> 전문가 로드맵의 법률·세무 내용은 일반 정보이며 전문가의 자문을 대신하지 않습니다.
